# Controller and Environment component - simulation cases with basic model

This folder contains simulation cases to validate the basic model of
the Controller and Environment component `CtrlEnv_Basic_refsub`.

To test the test target component `CtrlEnv_Basic_refsub`,
the harness model `HarnessModel_CtrlEnv` uses it together with
the simple plant model `CtrlEnv_Vehicle_refsub` in the `SubcomponentsForTesting` folder.
