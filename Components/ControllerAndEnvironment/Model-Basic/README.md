# Basic model of Controller and Environment component

This folder contains the basic model of the Controller and Environment component `CtrlEnv_Basic_refsub`.

The model is used as the "Controller and Environment" subsystem in the system-level BEV model `BEV_system_model`.

The model is tested as a main test target with a harness model `HarnessModel_CtrlEnv`.
The `SimulationCases` folder contains simulation cases to validate the model.
