Timed Trace Builder App

Use the Timed Trace Builder App to generate smooth timed signal data for lookup table blocks. The app provides high-level parameters to specify signal properties such as the number of transitions from one constant value to another, the range of constant values, and so on. Then the app generates data using a random seed. The app can send the generated data to lookup tables blocks.
