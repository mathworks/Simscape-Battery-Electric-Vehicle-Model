# Signal Tool

Signal tool provides a collection of utilities for designing and using signals
programmatically and graphically.
Signal tool also works with Simscape PS Lookup Table (1D) block and
Simulink 1-D Lookup Table block.

Use `SignalDesignApp` to design smooth or piece-wise linear signal traces.

<img src="screenshot-SignalDesignApp.png"
 alt="screenshot of Signal Design App" width="700"/>

Used `TimedTraceBuilderApp` to create and edit time-based signal traces
using high-level signal properties and a random seed.

 alt="screenshot of Timed Trace Builder App" width="800"/>
