# Utility

## Modeling Utility for Simscape

The folder `ModelingUtilityForSimscape` contains the [Modeling Utility for Simscape][modutilssc] (MUS),
which is a collection of APIs and apps to help streamline modeling workflows with Simscape.
The MUS was originally part of the BEV project but was separated to promote the reuse.
The APIs and apps are available with the namespace `bevutil*` (where `*` is a version number).
The resources are the same as the MUS except for the namespace.
The default namespace in the MUS is `mus*`, but it was changed to avoid namespace clash.

[modutilssc]: https://github.com/isaacito12/modutil-simscape

## Project Startup

The project automatically runs MATLAB code during startup.
See the Project Settings > Task Automation > Startup files.
