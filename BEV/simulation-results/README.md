# Simulation Results

This folder stores simulation results in the comma-separated-value (CSV) text format
generated by running the Live Script `BEV_main_script`.

The Live Script specifies the name of a CSV file with the variable `sim_result_filename`.

```matlab
sim_result_filename = "BEV_SimulationResult_1.csv";
```
